据 The Block 报道，Coinbase 旗下 Layer 2 网络 Base 的负责人 Jesse Pollak 表示，Base 应用将变得“更少以 Base 为中心”（less Base-centric）。这一表态出现在关于 Base 未来发展方向和生态建设的讨论中。

Pollak 指出，Base 在代币化（tokenization）和支付（payments）领域正看到不断增长的需求。他将 Robinhood 和 Stripe 推出的区块链相关项目称为对 Base 方向的“验证”（validation）。

此外，Pollak 提到 Cobie（知名加密社区人物）正在构建一个交易平台。该信息源自 The Block 的报道，具体平台细节尚未披露。

需要明确的是，这些表述来自 Pollak 的公开陈述，属于其个人观点和对趋势的解读，Base 未来的实际发展方向仍取决于后续执行和市场变化。
