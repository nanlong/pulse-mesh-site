据 The Block 报道，Cloudflare 已开启其稳定币钱包的推出进程。当前阶段，用户可以认领 Cloudflare 钱包句柄（wallet handles），但充值和支付功能尚未上线，将在后续阶段提供。

该钱包的核心定位是使 AI 代理能够使用稳定币支付 API 调用及在线内容访问费用。这标志着 Cloudflare 作为重要的互联网基础设施提供商，正尝试将加密支付能力嵌入 AI 代理的自动化工作流中。

**已确认事实：**
- Cloudflare 已启动稳定币钱包的推广，允许用户认领钱包别名。
- 钱包的充值与支付功能计划在稍后阶段推出。
- 该钱包面向 AI 代理，用于支付 API 和在线内容。

**推断与影响：**
- 此举可能为 AI 代理的经济活动提供标准化的链上支付基础设施，但具体支持的区块链网络、稳定币种类及费用结构尚未公布。
- 分阶段推出表明 Cloudflare 可能正在逐步验证合规与安全流程，当前阶段的实际支付能力仍然有限。
- 这是主流网络服务商将加密支付整合进 B2B 场景的信号，或将对传统 API 计量和计费方式产生长期影响，但短期效用依赖于后续功能的完善。

以上内容仅基于所提供来源报道，不构成投资建议。后续进展需关注 Cloudflare 的官方公告。
