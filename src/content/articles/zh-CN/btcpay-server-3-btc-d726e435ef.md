## 事件概述
据 The Block 报道，比特币支付处理软件 BTCPay Server 的支持者已提供最高 3 BTC 的恢复赏金，以应对一起严重漏洞利用事件。

## 已确认事实
- BTCPay Server 方面表示，该漏洞可能被 AI 利用。
- 本次漏洞由 Craig Raw 和 Bitcoin Red Team 基金报告。
- 支持者提供的恢复赏金上限为 3 BTC。

## 影响与推断
目前披露的信息有限，尚无关于漏洞具体技术细节或受影响用户范围的官方说明。可以推断的是，这一事件可能对依赖 BTCPay Server 进行支付处理的商户和服务商造成安全担忧。但上述推断尚未得到官方进一步证实。

这一事件提醒业界，开源支付基础设施同样面临复杂的安全威胁。对于使用相关服务的用户，建议密切关注官方后续公告。
